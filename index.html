How the projects are structured

Every project states one research question and the core experiment that answers it. Bachelor projects answer an empirical question about an established method using a fixed dataset, fair baselines and a careful analysis — no new architecture is required. Master projects add a new mechanism, view or protocol, multiple runs and a deeper analysis.

A controlled negative result is a valid outcome. Several projects state in advance that the expected answer to their question may be “no”; finding and explaining that is the contribution, not a failure.

Each project is labelled with one of three levels:

Level Meaning
BSc or MSc Both routes are viable; each scope box describes a separate project
BSc only Offered at Bachelor level
MSc preferred or MSc only Primarily offered at Master level; some list a reduced Bachelor version

What counts as a Bachelor or Master contribution

Dimension Bachelor project Master project
Starting point One dataset and one established method Verified anchor-paper reproduction plus required baselines
Contribution Documented pipeline, fair comparison and one focused ablation New mechanism, protocol, graph/view construction or transfer/robustness study
Evidence Correct split, sensible baselines and error analysis Multiple seeds, uncertainty, matched budgets, ablations and resource reporting where relevant
Outcome Explain whether and when the method helps Answer the stated question; a controlled negative result is valid

Shared protocol for self-supervised projects

Every self-supervised or pretrained project should report these settings whenever they are meaningful:

  1. Frozen linear evaluation. Pretrain without labels, freeze the encoder and train only a lightweight head.
  2. Fine-tuning. Initialise from the pretrained encoder and update it with labels.
  3. Fully supervised baseline. Train the same encoder architecture from scratch using labels.
  4. Random-initialisation control. Freeze a randomly initialised encoder and train the same head.
  5. Label-efficiency curve. Report several label budgets, typically 1%, 5%, 10% and 100%.

Leakage rule. Group splits by the real independent unit: subject, patient, household, engine, bearing or process cycle—never by window. On graphs, state whether pretraining is transductive or strict inductive. On forecasting tasks, preserve chronological order.
