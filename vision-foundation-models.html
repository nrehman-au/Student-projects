Category 3 Deep-learning vision models and applications

Frozen self-supervised backbones with lightweight task adaptation

A vision foundation model is a large image encoder pretrained on broad image collections so that its internal features can be reused for many later tasks. Vision Transformers divide an image into patches, treat those patches as tokens and learn relationships among them. Self-supervised models such as DINO learn useful visual structure without requiring a class label for every pretraining image.

In these projects, students do not train a foundation model from the beginning. They use a pretrained backbone as a frozen feature extractor and train only a small prediction head or adapter. For land-cover classification, the representation may separate forests, rivers and residential areas. For industrial inspection, patch-level representations may show where a surface differs from normal examples.

The central evaluation separates what the pretrained backbone already provides from what the student’s adaptation contributes. A frozen linear probe, a lightweight adapter and—where feasible—a full fine-tune are compared using the same labels, split and backbone. Performance is reported together with the number of trainable parameters and compute cost.

Choosing a project track

The project has two separate tracks. EuroSAT RGB supports the Bachelor classification route. MVTec dense anomaly localisation or multispectral EuroSAT supports a more complex Master route.

Learn first and find ideas

  • Core reading: DINO, DINOv2, the DINOv2 model card and code, DINOv3 and AnomalyDINO.
  • Data and model hubs: MVTec AD, EuroSAT, Hugging Face models and timm.
  • Keep zero-shot, one-shot, few-shot and full-shot anomaly results separate, and never compare an image-level metric directly with a pixel-level metric.

3.1 Adapting DINO backbones for land cover or industrial anomalies

TaskImage classification or image/pixel anomaly detection Recommended levelBSc or MSc with separate tracks ComputeModerate; frozen ViT-S practical on 8 GB, dense MSc work may need more Starting paperOquab et al., DINOv2, 2023

What you will do. Use a pretrained self-supervised vision transformer as a frozen feature extractor. Train a small head or adapter for a specialised task. Measure the performance of frozen features and test whether an adapter still contributes when a newer backbone is used.

Project goal. Quantify the trade-off among task performance, number of trainable parameters and supervision. Choose one track: EuroSAT RGB land-cover classification or MVTec industrial anomaly detection/localisation.

Data. BSc/default classification track: EuroSAT, 27,000 Sentinel-2 patches in 10 classes. Use the RGB version for ordinary DINO backbones; the 13-band version requires an explicit multispectral adapter and is a separate MSc question. MSc anomaly track: MVTec AD, more than 5,000 images in 15 categories with pixel masks, CC BY-NC-SA 4.0 for non-commercial research.

Methods and starting code. Default to DINOv2 ViT-S/14 from the official Apache-2.0 repository and model card. Compare frozen linear/MLP probes, k-NN or AnomalyDINO patch similarity, and a lightweight multi-scale adapter. DINOv3 is optional through the official repository; its weights are gated under a custom Meta licence.

Required baselines. From-scratch CNN, ImageNet-pretrained ResNet or ViT, frozen DINOv2 with no adapter, lightweight adapter and full fine-tuning only if hardware permits. On MVTec, include a simple nearest-neighbour patch baseline and keep zero-shot, one-shot, few-shot and full-shot protocols separate.

Evaluation. EuroSAT: top-1 accuracy, macro-F1, label-efficiency curve and trainable parameters. MVTec: image AUROC plus pixel AUROC/PRO or pixel F1-max, reported by category and protocol. Measure inference memory/latency. Never compare a one-shot image metric directly with a zero-shot pixel metric.

Bachelor scope. Use EuroSAT RGB. Compare a frozen DINOv2 ViT-S linear probe with an ImageNet-pretrained CNN and, if feasible, a small adapter at several label budgets.

Master research question and contribution. Choose one question. Dense anomaly route: can a supervised multi-scale adapter over frozen patch tokens improve few-shot localisation at a fixed label and parameter budget, and does the gain remain after switching DINOv2 to DINOv3? Remote-sensing route: can a small multispectral input adapter exploit 13 bands without full backbone fine-tuning? Report cross-version or cross-band ablations so the adapter’s value is isolated.

Practical notes. Do not attempt DINOv3 ViT-7B. DINOv2 is ungated and Apache 2.0; build the pipeline on it first. DINOv3’s licence is non-standard and gated but not stated as categorically non-commercial; an industry use requires institutional/legal review. MVTec itself is non-commercial, so it cannot serve as an industry dataset without separate permission.
