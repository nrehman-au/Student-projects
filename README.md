# Student Project Portfolio

This is the Quarto source for the BSc and MSc Student Project Portfolio in GNN applications, machine learning for time-series data, deep-learning vision, and signal processing.

## Preview locally

1. Install Quarto from <https://quarto.org/docs/get-started/>.
2. From this folder, run `quarto preview`.

## Render the static website

Run `quarto render`. The complete site is written to `_site/`.

## Publish with GitHub Pages

Repository: <https://github.com/nrehman-au/Student-projects>

Live website: <https://nrehman-au.github.io/Student-projects/>

The included **Quarto Publish** workflow renders the source and republishes the website whenever `main` is updated. GitHub Pages serves the generated `gh-pages` branch.
