Category 2 GNN applications for real-world data

Practical graph prediction problems with public benchmarks

A graph is a way to represent entities and the relationships between them. The entities are called nodes and their relationships are called edges. Both may carry useful information: a customer node might contain age or location, a product node might contain category and price, and an edge might record that a customer bought or rated a product. Road sensors connected by roads, transactions linked by payments and atoms connected by chemical bonds are other examples.

A graph neural network (GNN) learns numerical representations, or embeddings, by combining a node’s own features with information from its neighbours. In the example, the model can use a customer’s previous purchases, the properties of products and patterns from nearby customers to score a new customer-product link. The same principle supports node classification (classify a transaction), link prediction (recommend a product), and graph-level prediction (predict a property of an entire molecule or sensor system).

Each project asks when relationships between entities help prediction. Students begin with one simple reference model and one graph model, then investigate the value of the graph.

2.1 Predicting the remaining life of aircraft engines

LevelBSc or MSc ComputingStart with a small model; a GPU can help with training.

Goal

Predict how many operating cycles remain before a simulated aircraft engine fails. Investigate whether sharing information between related sensor channels improves predictions, and how the choice of sensor connections affects the result.

Data and starting material

Use the FD001 subset of NASA C-MAPSS, which contains simulated engine-degradation measurements from 21 sensor channels. It provides 100 training engines and 100 test engines.

  • Spatio-Temporal Attention GNN for Remaining Useful Life Prediction.
  • GNN remaining-life benchmark code.

Methods and evaluation

Explore time-series neural networks and spatiotemporal graph neural networks, which combine changes over time with relationships between sensors. Start with one model using sensor histories and one graph model.

Keep complete engines separate between training and evaluation, and measure the error in predicted remaining life. Compare meaningful sensor connections with shuffled connections and a version without information sharing.

Bachelor focus. How much does the choice of connections between sensors affect remaining-life prediction?

Master extension. Explore a model that adjusts sensor connections as an engine ages. Test whether it handles noisy or missing sensor measurements better than fixed connections.

2.2 Predicting traffic speed with graph neural networks

LevelBSc or MSc ComputingA GPU is recommended; requirements depend on the chosen model.

Goal

Predict traffic speed at road sensors 15, 30 and 60 minutes ahead. Investigate whether using information from connected sensors improves predictions compared with using each sensor’s own history, and whether this becomes more useful when forecasting further ahead. Each sensor represents a location in a graph; its connections allow the model to learn how traffic conditions at different locations relate to one another.

Data and starting material

Use METR-LA, which contains traffic-speed measurements from 207 sensors in Los Angeles, recorded every five minutes.

  • Dataset access and preparation instructions.
  • Graph WaveNet paper and authors’ code.

Methods and evaluation

Explore simple forecasting methods, time-series neural networks and spatiotemporal graph neural networks, which learn from both changes over time and relationships between sensors. Start with a simple reference method and one graph model.

Evaluate predictions on later data that the models have not seen, using average prediction error at the three forecasting horizons. Compare meaningful sensor connections with shuffled connections and a version without information sharing between sensors to establish when the graph helps.

Bachelor focus. Does information from connected sensors become more useful when predicting 60 minutes ahead than when predicting 15 minutes ahead?

Master extension. Explore a model that adjusts sensor connections as traffic conditions change. Test whether this improves 60-minute forecasts compared with connections that stay fixed, including during rush hour.

2.3 Detecting illicit Bitcoin transactions with graphs

LevelBSc or MSc ComputingA GPU is useful for graph models; begin with a small experiment.

Goal

Identify transactions labelled as associated with illicit activity. Investigate whether payment connections improve classification, and whether the model remains useful when some connections are missing.

Data and starting material

Use the Elliptic Bitcoin dataset through PyTorch Geometric. It provides transaction features, payment connections and labels for a subset of transactions. Transactions with unknown labels must remain unlabelled.

  • Dataset paper: Anti-Money Laundering in Bitcoin.
  • PyTorch Geometric code and examples.

Methods and evaluation

Explore conventional classifiers, such as random forests, and graph neural networks that use neighbouring transactions. Include a comparison using only the transaction’s own features, since some supplied features already summarise neighbours.

Train on earlier transactions and evaluate on later ones. Measure how well the models find illicit transactions while limiting false alarms, and repeat the comparison after removing some payment connections.

Bachelor focus. How much does missing payment information affect graph-based detection?

Master extension. Explore a model that accounts for changes over time or estimates uncertainty. Test whether its predictions remain reliable as transaction patterns change.

2.4 Recommending movies with graph neural networks

LevelBSc only ComputingA CPU or a small GPU is suitable for initial experiments.

Goal

Recommend films that a user has not yet rated. Investigate whether a graph of users and their ratings improves recommendations, and whether better accuracy comes at the cost of recommending a narrower range of films.

Data and starting material

Use MovieLens 100K, which contains 100,000 ratings from 943 users on 1,682 movies. The project uses ratings to identify films users like.

  • LightGCN paper and authors’ code.

Methods and evaluation

Explore popularity-based recommendation, matrix factorisation and graph-based recommendation, such as LightGCN. These approaches respectively use overall popularity, shared user–film patterns and connections in the rating graph.

Evaluate on later ratings kept out of the training graph. Compare recommendation quality and how widely the recommendations cover the film catalogue, including less popular films.

Bachelor focus. Does graph-based recommendation improve accuracy while still exposing users to a broad range of films? Study one factor, such as how far information travels through the graph.

2.5 Predicting molecular activity with graph neural networks

LevelBSc or MSc ComputingA GPU is recommended for the graph models.

Goal

Predict whether a molecule is active in an HIV screening assay. Investigate whether representing atoms and bonds as a graph helps the model generalise to molecular structures different from those used for training.

Data and starting material

Use OGB ogbg-molhiv, which contains 41,127 molecular graphs and an official split based on molecular structure. This is an assay-prediction task.

  • Open Graph Benchmark paper and code.
  • RDKit chemical-feature tools.

Methods and evaluation

Explore conventional classifiers using molecular fingerprints, which summarise chemical structure, and graph neural networks using atoms and bonds. Start with one fingerprint model and one graph model.

Use the official dataset split to evaluate on different molecular structures. Compare how well models distinguish active from inactive molecules and examine where their predictions fail.

Bachelor focus. Do graph neural networks generalise to new molecular structures better than traditional molecular fingerprints?

Master extension. Explore methods that make prediction confidence more reliable on unfamiliar structures. Test whether improved confidence estimates preserve classification performance.
