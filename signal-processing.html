Category 5 Signal processing and deep-unfolded models

Turning classical iterative signal-processing algorithms into trainable network layers

Many signal-processing methods repeat a fixed optimisation step until convergence. Algorithm unrolling, also called deep unfolding, turns a fixed number of those iterations into neural-network layers. The update equations determine the network structure, while selected algorithm parameters are learned from data.

This differs from Category 3: the network is a truncated version of a known algorithm, not a general-purpose encoder. Evaluation must therefore test both numerical correctness and the downstream task. Faster execution alone is insufficient if the learned layers no longer perform the intended decomposition.

A Master-level category

This category requires graduate-level optimisation and signal processing. The contribution is a justified change to the unrolled algorithm and a controlled comparison with the converged classical method.

Learn first and find ideas

  • General unrolling: Gregor & LeCun, Learning Fast Approximations of Sparse Coding (LISTA), ICML 2010 — the founding example, unrolling ISTA. Monga, Li & Eldar, Algorithm Unrolling, IEEE SPM 2021 — the field’s main survey. Yang, Sun, Li & Xu, Deep ADMM-Net for Compressive Sensing MRI, NeurIPS 2016 — unrolling a coupled, multi-variable ADMM iteration.
  • Signal decomposition: Dragomiretskiy & Zosso, Variational Mode Decomposition, IEEE TSP 2014, with reference Python code. Rehman & Aftab, Multivariate Variational Mode Decomposition, IEEE TSP 2019.
  • Ahmad, Wesemann, Waschkowski & Khalid, Robust Spatiotemporal Forecasting Using Adaptive Deep-Unfolded VMD, 2025 preprint, with authors’ repository — the anchor method for unrolling single-channel VMD. The repository currently has no licence file.

5.1 Deep-unfolded multivariate VMD for correlated multichannel signals

TaskUnroll multivariate VMD and evaluate decomposition, robustness and forecasting LevelMSc only ComputeLight for synthetic tests; moderate for LargeST-SD (12–24 GB GPU recommended) DataSynthetic multichannel signals plus LargeST-SD — 716 sensors, CC BY-NC 4.0 Starting paperAhmad, Wesemann, Waschkowski & Khalid, Adaptive Deep-Unfolded VMD, 2025

What you will do. Variational Mode Decomposition separates a signal into band-limited modes. MVMD extends it to several channels by estimating a shared centre frequency for each mode. You will turn a fixed number of MVMD iterations into trainable layers and test whether robust cross-channel weighting helps when some channels are noisy.

Project goal. Build a coupled unrolled MVMD whose output for one channel depends on the other channels. Replace equal averaging in the shared-frequency update with permutation-invariant weights derived from each channel’s residual. Test whether the weights reduce the influence of corrupted channels without collapsing onto one channel.

Data. First use synthetic signals with known modes and centre frequencies, 2–32 channels, varied SNR and controlled channel corruption. Then use the San Diego 2019 subset of LargeST: 716 traffic sensors aggregated to 15-minute intervals. The full California and Greater Los Angeles datasets are outside the project compute budget. LargeST data is CC BY-NC 4.0 and its benchmark code is MIT-licensed.

Methods and code. Validate classical MVMD using the original MATLAB implementation and an MIT-licensed Python implementation. Reimplement the UVMD equations from the anchor paper, then extend them to the coupled update. The authors’ MAGN repository may be inspected, but its code should not be copied or modified without licence clarification.

Baselines and evaluation. Compare per-channel VMD, converged MVMD, per-channel UVMD, equal-weight unrolled MVMD and the proposed robust-weighted version. On synthetic data report reconstruction error, centre-frequency error, runtime and performance across SNR, channel count and corrupted-channel fraction. On LargeST-SD use one fixed compact forecaster for raw data and every decomposition method; report MAE and RMSE at 15, 30 and 60 minutes. Use chronological splits and at least three seeds for learned methods.

Master research question. Can a fixed-depth unrolled MVMD match converged MVMD, and can residual-based channel weighting improve shared-frequency recovery when some channels are corrupted?

The minimum contribution is a correct coupled update, residual-based channel weighting, and an equal-weight ablation. Test unseen SNR levels and channel counts. LargeST-SD is a secondary test of whether decomposition improvements affect forecasting; it is not necessary to reproduce the full MAGN benchmark.

Practical notes. This is a high-risk MSc topic. In the first two weeks, recover known synthetic modes with classical MVMD, reproduce one UVMD result, and verify that one channel’s output has a non-zero gradient with respect to another channel’s input. Do not start LargeST until these tests pass. Regularise or constrain the channel weights and report their effective number so that apparent robustness is not produced by selecting one channel.
