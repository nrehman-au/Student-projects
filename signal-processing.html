Category 4 Signal processing and deep-unfolded models

Turning classical iterative signal-processing algorithms into trainable network layers

Many classical signal-processing methods are iterative optimisation algorithms: a decomposition, reconstruction or filtering result is obtained by repeating a fixed update rule until convergence, using hyperparameters that are set once and applied to every signal. Algorithm unrolling, also called deep unfolding, rewrites a fixed number of iterations of such an algorithm as the layers of a neural network. The algorithm’s update equations fix the network’s architecture, so the model stays interpretable, while its hyperparameters become trainable weights, learned end to end from data instead of tuned once by hand.

This differs from the representation-learning projects in Category 2: there, a generic encoder learns a representation through a self-supervised pretext task. Here, the network architecture itself is a classical algorithm, truncated to a handful of layers and made learnable. The typical finding across the field is that a handful of unrolled, learned iterations matches or beats an algorithm run to full convergence with a fixed hyperparameter, at a fraction of the compute.

From classical algorithm to learnable layer

Every project here starts from a published iterative algorithm and its update equations. The Bachelor-level bar is a correct, verified unrolled implementation compared against the classical algorithm. The Master-level bar is a new, justified design decision about what the unrolling makes learnable — not just reproducing an existing unrolled method on a new dataset.

Learn first and find ideas

  • General unrolling: Gregor & LeCun, Learning Fast Approximations of Sparse Coding (LISTA), ICML 2010 — the founding example, unrolling ISTA. Monga, Li & Eldar, Algorithm Unrolling: Interpretable, Efficient Deep Learning for Signal and Image Processing, IEEE SPM 2021 — the field’s main survey. Yang, Sun, Li & Xu, Deep ADMM-Net for Compressive Sensing MRI, NeurIPS 2016 — unrolling a coupled, multi-variable ADMM iteration.
  • Signal decomposition: Dragomiretskiy & Zosso, Variational Mode Decomposition, IEEE TSP 2014, and reference Python code. Rehman & Aftab, Multivariate Variational Mode Decomposition, IEEE TSP 2019.
  • Ahmad, Wesemann, Waschkowski & Khalid, Robust Spatiotemporal Forecasting Using Adaptive Deep-Unfolded VMD, 2025, and official code — the anchor paper for Project 4.1, unrolling single-channel VMD.

4.1 Deep-unfolded multivariate VMD for correlated multichannel signals

TaskAlgorithm unrolling: a coupled multivariate optimisation algorithm rewritten as learnable layers, evaluated as decomposition and as a forecasting preprocessing module Recommended levelMSc (a narrower BSc variant is possible, see Bachelor scope) ComputeLight for the synthetic benchmark; moderate for the applied task (single 8+ GB consumer GPU) Starting paperAhmad, Wesemann, Waschkowski & Khalid, Adaptive Deep-Unfolded VMD, 2025

What you will do. Variational Mode Decomposition (VMD) splits a signal into band-limited modes by solving a constrained optimisation problem with ADMM. A 2025 paper unrolls this ADMM iteration into a small stack of learnable layers (“UVMD”), replacing a fixed bandwidth hyperparameter with a learned one and cutting decomposition time roughly 250-fold — but only for a single channel at a time, applied independently channel by channel to multichannel data. Multivariate VMD (MVMD) already extends classical VMD to couple multiple channels through one shared, jointly estimated center frequency per mode. No deep-unfolded version of that coupled algorithm exists yet. You will design one.

Project goal. Unroll MVMD’s cross-channel frequency-coupling step into a learnable module that keeps the coupling genuine — rather than collapsing back into independent per-channel UVMD — and test whether coupling correlated channels, with the coupling weights themselves made learnable, improves decomposition accuracy, noise robustness and downstream task performance over both classical MVMD (accurate, slow) and independently-applied UVMD (fast, uncoupled).

Data. Required: a synthetic multichannel benchmark with known ground-truth modes, center frequencies and channel counts (2–32) at varied SNR, following the validation protocol in the VMD and MVMD papers — this is what the algorithm-design claims rest on. Required applied task: LargeST traffic forecasting (up to 8,600 California sensors, four regional subsets; also on Kaggle), the same benchmark the anchor paper uses — confirm its licence terms before allocation. Optional generalisation check: the CTU-UHB Intrapartum Cardiotocography Database (PhysioNet, open access, non-commercial use, 552 recordings), the same bivariate fetal heart rate / uterine contraction application MVMD’s own paper used.

Methods and starting code. Start from the anchor paper’s official UVMD implementation (uvmd.py) — both the baseline to beat (applied independently per channel) and the template to extend, since its unrolled ADMM layer is the single-channel building block. Use vmdpy as a numerically clean, non-unfolded reference for validating each unrolled layer. No Python port of classical MVMD exists yet; porting the official MATLAB implementation is an early, well-scoped first task and doubles as the classical baseline. For the applied task, reuse the anchor repository’s data pipeline and forecasting backbone so the decomposition module is the only substituted component.

Required baselines. Classical MVMD run to convergence; classical single-channel VMD applied independently per channel; UVMD (the anchor paper’s method) applied independently per channel — the direct competitor; the proposed jointly unrolled, learnably-weighted MVMD; and an ablation of the proposed method with the coupling step present but its channel weights fixed equal, to isolate whether coupling alone explains any gain or whether the learnable weighting does.

Evaluation. On the synthetic benchmark: per-mode reconstruction error against ground truth, center-frequency estimation error as a function of channel count and per-channel SNR, number of unrolled layers needed to match converged MVMD accuracy, and wall-clock decomposition time — reproduce the anchor paper’s speedup claim and check it survives adding coupling. On LargeST: MAE, RMSE and MAPE at prediction horizons 1–12 on at least two regions, plus decomposition time and trainable parameter count, comparing graph-neighbour channel groupings against all-channel pooling. Report at least three seeds for every learned method, and always report the fixed-weight ablation alongside any positive result.

Bachelor scope (if offered). Port classical MVMD to Python, unroll it with a fixed, non-learnable coupling step (skip the learnable channel-weighting question), and compare against per-channel UVMD and classical MVMD on the synthetic benchmark only — no applied dataset required. This is a reproduction-plus-one-extension study, smaller than the MSc contribution below.

Master research question and contribution. Research question: Does a jointly unrolled, learnably-weighted multivariate VMD recover shared oscillatory structure across correlated channels more accurately and more robustly to per-channel noise than either classical MVMD or independently-applied single-channel UVMD — and does that advantage survive into a downstream forecasting task? The minimum contribution is (1) a correctly implemented coupled unrolled update, verified not to silently collapse into independent per-channel UVMD, (2) a learnable channel-weighting mechanism in the coupling step, motivated and ablated against equal-weight pooling, and (3) the full baseline comparison on both the synthetic benchmark and LargeST. Reproducing the anchor paper’s per-channel UVMD alone is a reproduction study, not the contribution.

Practical notes. Validate every unrolled layer against vmdpy’s classical fixed-point update before adding any learning. Write an early test that would fail if the implementation reduced to independent per-channel UVMDs (e.g. verify one channel’s output has a non-zero gradient with respect to another channel’s input) — the cross-channel coupling is the entire point of this project. Confirm LargeST’s licence before committing to it; the synthetic benchmark plus the openly licensed CTU-UHB database is a sufficient fallback applied study on its own. The anchor repository has no licence file — check with its authors before reusing its code beyond research and study.
